# PRÉPA BEPC — application Android

Application officielle de préparation au BEPC (Côte d'Ivoire) : 300 exercices corrigés de Maths et de Physique-Chimie.

**Pour l'installer, passez par la page officielle : https://prepabepc.pages.dev/android**

Ce dépôt ne contient que le fichier d'installation (`prepa-bepc.apk`). N'installez jamais un fichier PRÉPA BEPC reçu d'une autre source.

Sur iPhone, utilisez directement https://prepabepc.pages.dev dans Safari.
